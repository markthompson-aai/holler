## Blurt

Holler depends on Blurt's engine (`BlurtEngine`, fetched by Swift Package Manager) for mic capture, the Dictation API client, the hotkey and API key storage, and its streaming audio player is adapted from Blurt's read-aloud engine.

Source: https://github.com/AssemblyAI/blurt
